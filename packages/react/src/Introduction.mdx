# @bpdm/ui

A modern, themeable, accessible **React component library** — **38 components** built
on Radix primitives and Tailwind CSS&nbsp;4, with a warm amber design system, four
built-in themes, and one consistent motion language.

The React implementation of the **bpdm design system** — one set of design tokens,
built for every framework. _(Angular is coming soon — pick a framework on the
[live site](https://ui.bpdm.dev).)_

[Live site](https://ui.bpdm.dev) · [npm](https://www.npmjs.com/package/@bpdm/ui) · [GitHub](https://github.com/bpdm-hq/bpdm-ui)

---

## Why @bpdm/ui

- **Accessible by default** — keyboard, focus, and ARIA handled via Radix primitives.
- **Themeable** — components read semantic CSS variables; switch the whole UI with one
  `data-theme`, or override variables to match your brand. _Try the **Theme** switcher
  in the toolbar above ↑._
- **Four themes** — `paper` & `mist` (light), `charcoal` & `slate` (dark).
- **One motion language** — shared easing/duration tokens; honors `prefers-reduced-motion`.
- **Typed & tree-shakeable** — full TypeScript types, ESM + CJS, `sideEffects: false`.

## Install

```bash
pnpm add @bpdm/ui
# peers: react >= 18, react-dom >= 18 — and Tailwind CSS 4 in your app
```

In your global CSS:

```css
@import "tailwindcss";
@import "@bpdm/ui/styles.css";              /* design tokens + themes */
@source "../node_modules/@bpdm/ui/dist";    /* let Tailwind scan the components */
```

Pick a theme on any ancestor (default `paper`):

```html
<html data-theme="slate"> <!-- paper · mist · charcoal · slate -->
```

## Quick start

```tsx
import { Button, Input, Checkbox } from "@bpdm/ui";

export function Example() {
  return (
    <form className="space-y-3">
      <Input placeholder="you@company.com" type="email" />
      <label className="flex items-center gap-2">
        <Checkbox /> Remember me
      </label>
      <Button>Sign in</Button>
    </form>
  );
}
```

## Theming

Components never hardcode colors — they read CSS variables. Re-brand by overriding
them, globally or scoped:

```css
:root {
  --primary: #7c3aed;          /* your brand color    */
  --ring: #7c3aed;             /* matching focus ring */
  --primary-foreground: #fff;  /* text on primary     */
}
```
