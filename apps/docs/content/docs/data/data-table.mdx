The **Data Table** is fully data-driven: describe your `columns` once and pass an
array of `data` — no per-cell markup. Density, striping, sorting, selection,
pagination, filtering, column pinning, row expansion, a column toggle, global
search, reordering and virtualization are all opt-in props. In Angular it's
`<bpdm-data-table>` with the same `columns` / `data` inputs; custom cells use an
`<ng-template>` instead of React's inline `cell`.

## Usage

Each column has an `id`, a `header`, and an `accessor` (plain value) or `cell`
(custom node). Pass a `rowKey` so selection/expansion survive sorting.

```tsx title="members-table.tsx"
import { DataTable, type DataTableColumn } from '@bpdm/ui/data-table';

type Member = {
  id: string;
  name: string;
  email: string;
  role: string;
  status: 'active' | 'invited' | 'disabled';
  tasks: number;
};

const members: Member[] = [
  { id: 'm1', name: 'Hugo Lindberg', email: 'hugo@acme.dev', role: 'Owner', status: 'active', tasks: 128 },
  { id: 'm2', name: 'Sara Kovac', email: 'sara@acme.dev', role: 'Editor', status: 'active', tasks: 86 },
  { id: 'm3', name: 'Noah Bauer', email: 'noah@acme.dev', role: 'Viewer', status: 'disabled', tasks: 12 },
];

const columns: DataTableColumn<Member>[] = [
  { id: 'name', header: 'Name', sortable: true, accessor: (r) => r.name },
  { id: 'email', header: 'Email', accessor: (r) => r.email, className: 'font-mono text-xs' },
  { id: 'role', header: 'Role', sortable: true, accessor: (r) => r.role },
  { id: 'status', header: 'Status', align: 'center', cell: (r) => <StatusBadge status={r.status} /> },
  { id: 'tasks', header: 'Tasks', numeric: true, sortable: true, accessor: (r) => r.tasks },
];

export function MembersTable() {
  return <DataTable columns={columns} data={members} rowKey={(r) => r.id} />;
}
```

`accessor` columns render as text; for a custom cell use an `<ng-template>` and
point the column's `cell` at it.

```ts title="members-table.ts"
import { Component, viewChild, computed, type TemplateRef } from '@angular/core';
import { BpdmDataTable, type DataTableColumn } from '@bpdm/ng';

type Member = { id: string; name: string; email: string; role: string; status: string; tasks: number };

@Component({
  selector: 'members-table',
  imports: [BpdmDataTable],
  templateUrl: './members-table.html',
})
export class MembersTable {
  readonly statusCell = viewChild.required<TemplateRef<unknown>>('statusCell');

  readonly members: Member[] = [
    { id: 'm1', name: 'Hugo Lindberg', email: 'hugo@acme.dev', role: 'Owner', status: 'active', tasks: 128 },
    { id: 'm2', name: 'Sara Kovac', email: 'sara@acme.dev', role: 'Editor', status: 'active', tasks: 86 },
    { id: 'm3', name: 'Noah Bauer', email: 'noah@acme.dev', role: 'Viewer', status: 'disabled', tasks: 12 },
  ];

  readonly columns = computed<DataTableColumn<Member>[]>(() => [
    { id: 'name', header: 'Name', sortable: true, accessor: (r) => r.name },
    { id: 'email', header: 'Email', accessor: (r) => r.email, className: 'font-mono text-xs' },
    { id: 'role', header: 'Role', sortable: true, accessor: (r) => r.role },
    { id: 'status', header: 'Status', align: 'center', cell: this.statusCell() },
    { id: 'tasks', header: 'Tasks', numeric: true, sortable: true, accessor: (r) => r.tasks },
  ]);
}
```

```html title="members-table.html"
<bpdm-data-table [columns]="columns()" [data]="members" [rowKey]="(r) => r.id" />

<ng-template #statusCell let-row>
  <span class="rounded-full px-2 py-0.5 text-xs capitalize">{{ row.status }}</span>
</ng-template>
```

## Pagination

Pass `pagination` for client paging (the table slices `data`). Use
`mode: 'server'` (offset — you supply `total` + handle `onPageChange`) or
`mode: 'cursor'` (prev/next only) for server-driven data.

<Preview>
  <DataTablePaginationDemo />
</Preview>

<Tabs groupId="framework" items={['React', 'Angular']}>
  <Tab value="React">

```tsx title="data-table-pagination.tsx"
// client (default) — the table pages the data itself
<DataTable columns={columns} data={members} rowKey={(r) => r.id}
  pagination={{ pageSize: 8, pageSizeOptions: [8, 16, 32] }} />

// server (offset) — you provide the current page's rows + total
<DataTable columns={columns} data={pageRows} rowKey={(r) => r.id}
  pagination={{ mode: 'server', page, pageSize: 20, total, onPageChange: setPage }} />

// cursor — prev/next only
<DataTable columns={columns} data={pageRows} rowKey={(r) => r.id}
  pagination={{ mode: 'cursor', hasNextPage, hasPreviousPage, onNextPage, onPreviousPage }} />
```

## API

### `DataTable` / `<bpdm-data-table>`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `columns` | `DataTableColumn<T>[]` | — | **Required.** Column definitions. |
| `data` | `T[]` | — | **Required.** Row data. |
| `rowKey` | `(row, i) => Key` | index | Stable key (needed for selection/expansion across sorting). |
| `size` | `sm \| md \| lg` | `md` | Cell density. |
| `striped` / `bordered` / `frame` / `divided` | `boolean` | — / — / `true` / `true` | Zebra rows / column dividers / outer frame / row dividers. |
| `hoverable` | `boolean` | `true` | Highlight the hovered row. |
| `stickyHeader` + `maxHeight` | `boolean` + `number \| string` | — | Pin the header while the body scrolls. |
| `onRowClick` | `(row, i) => void` | — | Make rows clickable. |
| `multiSort` / `sort` / `defaultSort` / `onSortChange` | — | — | Sorting (per-column `sortable`). |
| `selectable` / `selectionMode` / `selectedKeys` / `onSelectionChange` | — | — | Row selection (`multiple` \| `single`). |
| `pagination` | `client \| server \| cursor` | — | Paging config. |
| `renderExpanded` / `expandMode` / `expandedKeys` | — | — | Expandable detail rows. |
| `pinnable` / `columnToggle` / `searchable` / `responsive` / `virtualized` | `boolean` | — | Opt-in features. |
| `reorderableColumns` / `reorderableRows` | `boolean` | — | Drag to reorder columns / rows. |
| `emptyContent` | `ReactNode` | `No data` | Empty-state content. |

### `DataTableColumn<T>`

`id`, `header`, `accessor`, `cell` (React node / Angular `<ng-template>`),
`footer`, `align`, `width`, `numeric`, `pin`, `hideable`, `filterable`,
`filterType`, `filterOptions`, `sortable`, `sortAccessor`, `className`.

## Accessibility

- Renders a real semantic `<table>` (`thead` / `tbody` / `th` / `td`), so screen
  readers and keyboard navigation work natively.
- Sortable headers are buttons and expose **`aria-sort`**; the selection column's
  checkboxes/radios are labelled, and "select all" toggles the page.
- The sticky header and horizontal scroll keep headers associated with their
  cells; pinned columns stay reachable.
- Provide a meaningful `header` per column — it's the accessible name for every
  cell in that column.
