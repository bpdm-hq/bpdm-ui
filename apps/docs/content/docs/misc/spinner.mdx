The **Spinner** signals indeterminate loading. It inherits the current text
colour (recolour with a `text-*` class), comes in five sizes, and announces
itself to assistive tech. `LoadingOverlay` pairs it with a blurred scrim to cover
a card or the whole screen while it loads. In Angular they're `<bpdm-spinner>`
and `<bpdm-loading-overlay>`.

## Loading overlay

`LoadingOverlay` covers its nearest positioned ancestor (give it `relative`) with
a blurred scrim and a centred spinner. Set `fullPage` to cover the viewport
instead. Click **Refresh** below to see it scoped to the card.

<Preview>
  <SpinnerOverlayDemo />
</Preview>

<Tabs groupId="framework" items={['React', 'Angular']}>
  <Tab value="React">

```tsx title="loading-overlay.tsx"
import { useState } from 'react';
import { LoadingOverlay } from '@bpdm/ui/spinner';
import { Button } from '@bpdm/ui/button';

export function Card() {
  const [loading, setLoading] = useState(false);
  const refetch = () => {
    setLoading(true);
    setTimeout(() => setLoading(false), 1800);
  };
  return (
    <div className="space-y-3">
      <div className="relative overflow-hidden rounded-xl border bg-card p-5">
        <p className="text-sm text-muted-foreground">Active users</p>
        <p className="mt-1 text-2xl font-semibold">12,480</p>
        <LoadingOverlay show={loading} label="Fetching…" />
      </div>
      <Button size="sm" variant="secondary" appearance="outline" onClick={refetch}>
        Refresh
      </Button>
    </div>
  );
}
```

  </Tab>
  <Tab value="Angular">


## API

### `Spinner` / `<bpdm-spinner>`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `ring \| gradient \| square \| dots \| bars \| flip` | `ring` | Visual style. |
| `size` | `xs \| sm \| md \| lg \| xl` | `md` | Spinner size. |
| `label` | `string` | `Loading` | Visually-hidden accessible label. |

Recolour with any `text-*` class — the spinner inherits `currentColor`.

### `LoadingOverlay` / `<bpdm-loading-overlay>`

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `show` | `boolean` | `true` | Render the overlay. |
| `label` | `string` | — | Message shown under the spinner. |
| `variant` | `SpinnerVariant` | `ring` | Spinner style. |
| `size` | `SpinnerSize` | `md` (`lg` if `fullPage`) | Spinner size. |
| `fullPage` | `boolean` | `false` | Cover the viewport instead of the ancestor. |
| `blur` | `boolean` | `true` | Blur the content behind the scrim. |

## Accessibility

- The spinner is a live region — `role="status"` with `aria-live="polite"` — and
  carries a visually-hidden `label` (default "Loading") so screen readers
  announce the loading state.
- Set a meaningful `label` for context (e.g. "Loading results", "Saving").
- `LoadingOverlay` also sets `aria-busy="true"` while shown.
- The animation respects `prefers-reduced-motion`.
