**bpdm/ui** is an accessible, themeable component library built on one shared set of
design tokens — with native implementations for **React** (`@bpdm/ui`) and
**Angular** (`@bpdm/ng`). Same look, same behavior, in both frameworks.

## Why bpdm/ui

- **One source of truth** — colors, spacing, radius and motion live in `@bpdm/tokens`; both frameworks render identically.
- **Accessible by default** — built on Radix (React) and the Angular CDK, following WAI-ARIA patterns.
- **Themeable** — four built-in themes via a `data-theme` attribute; override any token.
- **38 components**, shipping in both frameworks today.

<Callout type="info">
  Every package is published on npm under the `@bpdm/` scope — install what you need, or
  browse every component live at [ui.bpdm.dev](https://ui.bpdm.dev).
</Callout>

## Installation

<Tabs items={['React', 'Angular']}>
  <Tab value="React">
```bash
npm install @bpdm/ui
```
  </Tab>
  <Tab value="Angular">
```bash
npm install @bpdm/ng
```
  </Tab>
</Tabs>

Import the design tokens once in your global stylesheet (after Tailwind):

```css
@import "tailwindcss";
@import "@bpdm/tokens/tokens.css";
```
